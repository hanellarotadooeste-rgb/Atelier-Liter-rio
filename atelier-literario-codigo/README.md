# Atelier Literário - Diário Literário & Photo Dump Generator

Aplicativo de organização literária e diário de leitura pessoal com gerador de **Photo Dump para Instagram** (estética Pinterest, Canva e Scrapbook).

## 🚀 Como Executar Localmente

1. Extraia o arquivo ZIP em uma pasta do seu computador.
2. Abra o terminal na pasta extraída e instale as dependências:
   ```bash
   npm install
   ```
3. Execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

## 📦 Estrutura do Projeto

- `App.jsx` - Componente principal com gerador de Photo Dump, biblioteca, seletor de paletas de cor do app e fechamento mensal.
- `package.json` - Configuração das dependências do projeto React + Vite + Tailwind CSS.
